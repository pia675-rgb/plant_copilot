# 패치 19-8 — 출력 리스트 흡수 + 인사 응대

패치 19-7 위에 덮으십시오.

```
data/make_io_list.py             출력을 IO List 의 DO/AO 점으로 흡수
data/IO_LIST.xlsx                76 → 100점 (출력 24점 추가, 배선 공란)
data/INSTRUMENT_LIST.xlsx        21열 100점 (TYPE·FAIL POSITION·DRIVE 추가)
config.py                        OUTPUT_LIST_XLSX → 계기 리스트를 가리킴
retrieval/panel_index.py         배선 없는 점은 판넬·카드 조회에서 제외
api/server.py                    인사 응대 · 질문 판정 정정 · 포괄 응답 문구
eval/selfcheck.py                인사 응대 [주입] (28 → 29)
data/DEMO_OUTPUT_LIST.xlsx       삭제
```

## 1. 출력 리스트를 흡수했습니다

실제 프로젝트에 "output list" 문서는 없습니다. 출력은 **IO List 의 DO/AO
점**이고, 고장 위치·구동 방식은 계기 리스트에 있습니다.

```
IO List        입력 76 + 출력 24 = 100점
계기 리스트     100점 (TYPE · FAIL POSITION · DRIVE 열 추가)
```

**배선 열(PANEL·RACK·SLOT·CH)은 비웠습니다.** 랙·슬롯·채널을 지어낼 수
없습니다. 그러면 "IO List 에 있으나 배선 미정" 상태가 되고, 실물에서
채워야 할 칸이 정확히 드러납니다. REMARK 에도 그렇게 적힙니다.

판넬·카드 조회는 배선 있는 76점만 대상으로 합니다. 배선이 비었다고
추정해 채우지 않습니다.

### 교차 정합성 36건 → 6건

```
전         출력 태그 출처 불명 19 · 조건 태그 출처 불명 15 · 태그 형식 아님 2
후         조건 태그 출처 불명  4 · 태그 형식 아님 2
```

남은 4건(`AIT-6004` `FIT-5006` `LIT-7003` `TIT-5005`)은 인터락 조건에만
나오고 계기 리스트에 없는 태그입니다. 2건(`STAND-BY`,
`DMF-RW-01A~I`)은 파서가 조건 문구에서 뽑은 것으로 태그가 아닙니다.

### 원천은 v1 에 둡니다

처음에 흡수 원천을 v2 `data/` 로 잡았다가, 그 파일을 지우면 다음
재생성에서 출력이 통째로 사라지는 것을 확인했습니다. 흡수가 일회성이
되면 안 됩니다. 원천은 v1 `demo_data/` 에 두고 v2 `data/` 에는 **생성물만**
남깁니다.

```
data/ 엑셀   IO_LIST · INSTRUMENT_LIST (생성물)
             DEMO_INTERLOCK_LIST · INTERLOCK_SAMPLE (인터락 생성물)
             maintenance_history (v1부터 있던 데모 파일)
```

## 2. ★ 인사에 예시 목록이 나가던 문제

```
나:  안녕하세요
봇:  예) AIT-4002 low acid 알람 조회해줘 / XV-4101 인터락 조회 / 사용법

나:  인사안해주고 예시를 들어주네?
봇:  매뉴얼에서 근거를 찾지 못했습니다. 검색 결과 없음
```

두 군데가 겹쳤습니다.

**첫째, 인사가 아무 규칙에도 걸리지 않아 포괄 응답으로 떨어졌습니다.**
포괄 응답이 예시 나열이라 무시당한 느낌을 줍니다. 인사·감사·작별·신원·
기능 질문을 `smalltalk_intent` 로 받습니다.

```
안녕하세요     → 안녕하세요. 계기 알람·인터락·판넬 조회를 도와드립니다.
고마워         → 도움이 되었다면 다행입니다.
너 누구야      → 계기 리스트·인터락 리스트·매뉴얼에 있는 내용만 답합니다.
뭐 할 수 있어? → 알람 조회, 인터락 조회, 판넬·카드 조회, 도면 보기
```

길이를 24자로 제한했습니다. "안녕하세요 그런데 AIT-1001 판넬 어디야" 를
인사로 삼키면 안 되기 때문입니다.

**둘째, 물음표 하나로 매뉴얼 질문이라고 판정했습니다.** `looks_like_question`
의 정규식에 `\?` 가 통째로 들어 있어서, "인사 안 해주고 예시를 들어주네?"
가 매뉴얼 검색으로 넘어가 "근거를 찾지 못했습니다" 가 나왔습니다.
의문사·요청어가 실제로 있어야 질문으로 봅니다.

**셋째, 포괄 응답 문구를 바꿨습니다.** 예시만 나열하지 않고 무엇을
말하면 되는지 먼저 안내합니다.

## 3. 점검기가 스스로 깨졌습니다

`챗봇 명령 실행 [주입]` 이 실패했습니다. 이 항목은 "규칙의 예시 문구가
LLM 답을 덮지 않는가" 를 보는데, 탐침으로 **"안녕하세요"** 를 쓰고
있었습니다. 인사를 규칙이 응대하게 되면서 탐침이 더 이상 포괄 응답
경로를 지나지 않게 된 것입니다.

검사 의도는 그대로 두고 탐침만 규칙에 걸리지 않는 잡담으로 바꿨습니다.
**항목을 지우지 않았습니다** — 원래 보려던 고장은 여전히 가능합니다.
