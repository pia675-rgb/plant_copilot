## 이번 점검에서 추가로 고친 것

오늘 반복된 유형 — **실패를 삼키는 곳** — 을 다시 훑어 세 곳을 고쳤습니다.

### 1. `known_tags()` 가 실패를 삼키고 있었습니다

계기 리스트 적재가 실패하면 태그 목록이 빈 집합이 되고, 그러면 챗봇이
**멀쩡한 태그에도 "리스트에 없습니다"** 라고 답합니다. 원인을 찾기
어려운 종류의 고장입니다. 사유를 남기고 `/api/health` 의
`tag_index_error` 로 드러냅니다. `known_tags` 개수도 함께 실립니다.

### 2. `/health` 실패를 화면이 삼키고 있었습니다

health 가 실패하면 강등 배너가 **영원히 안 뜹니다.** 즉 검색이
렉시컬로 강등돼도 화면은 조용합니다. 이제 상태 확인 실패 자체를
배너로 띄웁니다.

### 3. 챗봇 오프라인 폴백이 조용했습니다

백엔드에 못 닿으면 화면 안의 간이 파서로 내려가는데, 조용히 내려가면
왜 답이 달라졌는지 알 수 없습니다. 응답에 `(오프라인 해석 — 서버에
연결하지 못했습니다)` 를 붙입니다.
