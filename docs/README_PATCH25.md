# 패치 25 — 계통(SYSTEM) 좁히기 제거

## 왜 뺐나

사이드바의 "계통 좁히기" 는 `SYSTEM` 열에서 목록을 만들었습니다. 그런데
그 열은 **넣으시는 아홉 가지 자료 어디에도 없습니다.** 데모 원천에만
있어서 제가 만든 부속 데이터로 넘어온 값이고, 실물로 갈아 끼우면 목록이
통째로 빕니다. `DRIVE` 와 같은 상황인데 화면에서 눈에 띄는 자리라 더
곤란합니다.

`LOOP GROUP` 도 같은 상태라 함께 뺐습니다.

## 무엇이 없어졌나

```
사이드바      계통 좁히기 드롭다운 → 제거 (태그·서비스·모델 검색으로 대신)
계기 상세     계통 · Loop Group 칸 → 제거
4D 리포트     계통 표시 → 제거, 조치 항목 "동일 계통" → "동일 판넬·카드"
API           /api/tags 의 systems → 빈 목록 (하위 호환)
부속 데이터    SYSTEM · LOOP GROUP 열 → 제거
```

## 상실 범위는 단자대(TB) 로 묶습니다

카드가 죽었을 때 "몇 개 시스템에 분산" 이라고 보여주던 자리입니다.
계통이 없어졌으니 **단자대 기준**으로 바꿨습니다. TB 는 TB List 에서
실제로 오는 값이라 실물에서도 채워집니다.

```
전   잃는 계기 3점 · 2개 시스템에 분산
후   잃는 계기 3점 · 단자대 3곳
       TB2  1  AIT-1001
       TB6  1  TIT-4004
       TB7  1  TIT-4008
```

배치도 일람표의 `SYSTEMS SERVED` 칸도 `TB GROUPS` 로 바꿨습니다.

## 평가 채점기도 함께 고쳤습니다

`roster` 문항이 시스템 집계를 대조하고 있어 단자대 집계로 바꿨는데,
처음 고친 판이 **출력 24점에서 실패**했습니다. 그 24점은 TB List 에 없어
단자가 비어 있는데, 채점기가 "빈 것" 과 "틀린 것" 을 구분하지 못했습니다.
단자가 있는 것만 대조하도록 고쳤습니다.

## 부속 데이터에 남은 것

```
TERMINAL       TB List 가 원본
TYPE           계기 리스트 SENSOR TYPE 이 원본
FAIL POSITION  인터락 리스트 Valve Action 이 원본
MANUAL FILE    자동 대조 미구현 — 이것만 남았습니다
```

`MANUAL FILE` 은 계기 리스트의 MAKER·MODEL 과 매뉴얼 파일명을 대조해
도구가 이을 수 있습니다. 지금 파일명이 모델명을 담고 있어 가능합니다.
붙이면 부속 데이터를 통째로 없앨 수 있습니다.
