# 패치 13 — 챗봇 인터락 조회에 원본 블록 누락

`ui/react/src/App.jsx` 한 파일만 바뀝니다. (`index.css` 는 사이드바 접기
포함 최신본이라 함께 넣었습니다 — 이미 적용하셨으면 덮어써도 동일합니다.)

## 무엇이 문제였나

같은 인터락 결과 화면인데 **경로에 따라 원본 블록이 붙기도 하고 안
붙기도 했습니다.**

| 경로 | 원본 블록 |
|---|---|
| 화면의 조회 버튼 | 항상 표시 |
| 챗봇 `LCV-01 인터락 조회해줘` | **없음** |
| 챗봇 `LCV-01 인터락 원본 보여줘` | 표시 |

챗봇 경로가 `interlock_source` 의도일 때만 원본을 불러오고 있었습니다.
버튼 경로는 언제나 불러오는데도요.

## 왜 중요한가

**원본 대조는 이 기능의 핵심입니다.** 기획서 3-4절에 "조회 결과 옆에
인터락 리스트 엑셀의 원본 행을 함께 띄워 사람이 직접 대조할 수 있게
한다" 고 적었고, 인터락에서 환각을 막는 근거로 내세운 것이 이것입니다.

시연에서 챗봇으로 조회하면 그 근거가 화면에 없는 상태가 됩니다.

## 고친 것

챗봇 경로도 원본 블록을 **항상** 불러옵니다. `interlock_source` 는
불러오느냐가 아니라 **자동으로 펼치느냐**의 차이가 됩니다.

이전 조회의 원본이 남아 있지 않도록 진입 시 초기화도 넣었습니다.

## 확인

백엔드 재시작 없이 `npm run dev` 가 돌고 있으면 저장 즉시 반영됩니다.

챗봇 하단 칩으로 두 가지를 눌러 비교해 보십시오.

- `실물 인터락` (`LCV-01 OPEN 인터락 조회해줘`) → 조건과 **원본 블록**
- `원본 리스트` (`LCV-01 인터락 원본 보여줘`) → 같은 화면, 원본이 펼쳐진 상태

둘 다 원본 블록이 보이면 정상입니다.
