# 패치 14 — 도면 드래그가 안 되던 문제

`ui/react/src/App.jsx` 한 파일만 바뀝니다. 패치 13 내용을 포함합니다.
(`index.css` 는 최신본을 함께 넣었습니다 — 이미 적용하셨으면 동일합니다.)

## 원인

`ZoomableImage` 에 이런 효과가 있었습니다.

```jsx
React.useEffect(() => {
  setScale(1)
  setPos({ x: 0, y: 0 })     // ← 위치 초기화
  setDpi(160)
  setImgSrc(buildSrc(160))
}, [buildSrc])                // ← 의존성이 "함수 자체"
```

호출부는 `buildSrc` 를 **인라인 화살표 함수**로 넘깁니다.

```jsx
<ZoomableImage buildSrc={(dpi) => `${API}/drawing-page?...&dpi=${dpi}`} />
```

인라인 함수는 렌더마다 새 객체입니다. 따라서

```
드래그 → setPos → 리렌더 → 새 buildSrc → 효과 실행 → setPos({0,0})
```

**매 프레임 위치가 0,0 으로 되돌아갔습니다.** 확대가 멀쩡했던 것은
배율 반영이 180ms 디바운스를 거쳐 별도 경로로 적용되기 때문입니다.
그래서 "확대축소는 잘 되는데 드래그만 안 된다" 로 보였습니다.

## 고친 것

### 1. 의존성을 함수가 아니라 문자열로

```jsx
const baseSrc = buildSrc(160)      // 실제 URL
React.useEffect(() => { ...리셋... }, [baseSrc])
```

같은 도면을 보는 동안 `baseSrc` 는 값이 같으므로 효과가 다시 돌지
않습니다. 전체/크롭을 전환하거나 다른 페이지로 가면 URL 이 바뀌어
정상적으로 리셋됩니다.

### 2. 드래그 자체도 손봄

- `onPointerDown` 에서 `preventDefault()` — 텍스트 선택이 시작되면
  드래그가 끊깁니다
- `onPointerLeave` 로 드래그를 끝내던 것을 `onPointerCancel` 로 교체 —
  포인터 캡처가 걸린 상태에서 뷰포트 밖으로 나갔다는 이유로 중단되지
  않게 합니다
- `setPointerCapture` 실패를 무시하도록 감쌈

## 확인

`npm run dev` 가 돌고 있으면 저장 즉시 반영됩니다.

1. 도면을 열고 휠이나 ＋ 로 200% 정도 확대
2. 도면을 잡고 끌기 — 따라와야 합니다
3. `전체 도면` / `태그 확대` 전환 — 이때는 배율·위치가 리셋되어야 합니다

3번이 되어야 리셋 조건을 제거한 게 아니라 올바르게 좁힌 것입니다.

## 같은 유형입니다

오늘 잡은 것들과 성격이 같습니다 — 실패가 조용하고, 화면은 그럴듯하고,
증상만 보면 원인이 엉뚱한 곳(드래그 핸들러)에 있는 것처럼 보입니다.
실제 원인은 의존성 배열 한 줄이었습니다.
