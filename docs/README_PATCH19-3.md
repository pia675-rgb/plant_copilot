패치 19-2 및 경민님이 직접 손보신 챗봇 개선 위에 덮으십시오.

```

data/make_arrangement.py    계기 리스트를 config.INSTRUMENTS 한 곳에서만 읽음
retrieval/panel_index.py    PANEL_LOCATIONS 의 POINTS 를 조회에 노출

eval/scorecard_panel.md     재측정
```

## 1. ★ 넓힌 거절이 매뉴얼 질문을 삼키고 있었습니다

`rule_intent` 의 조건을 `if miss and not tag` 에서 `if miss` 로 넓히신 것,
그리고 규칙이 "없습니다" 를 확정하면 QA/LLM 으로 넘기지 않게 하신 것 —
방향은 맞습니다. 없는 판넬 이름을 지어내는 것보다 훨씬 낫습니다.

그런데 태그 정규식은 태그가 아닌 것도 잡습니다.

```
PCS 7 에서 알람 확인하는 법 알려줘      → PCS-7 는 계기 리스트에 없습니다
TB2 단자대가 뭐야                     → TB-2 는 계기 리스트에 없습니다
NAMUR NE43 이 뭐야                   → NAMUR-NE43 는 계기 리스트에 없습니다
bge-m3 임베딩이 뭐야                  → BGE-M3 는 계기 리스트에 없습니다
AI 16xI 모듈 상태 표시 설명해줘         → AI-16XI 는 계기 리스트에 없습니다
```

마지막 줄이 특히 아픕니다. **`AI 16xI` 는 매뉴얼 6.1 절 제목**입니다.
매뉴얼 검색이 답해야 할 질문이 태그 오타로 오인되어 거절되고, QA 경로로
넘어가지도 못했습니다.

### 강·약 두 등급으로 나눴습니다

| 등급 | 조건 | 처리 |
|---|---|---|
| **강함** | 접두어가 실재 태그 접두어 (AIT-9999, XV-1234) | 거절하고 QA 로도 안 넘김 |
| **약함** | 숫자는 있으나 접두어가 낯섦 (PCS 7, TB2, AI 16xI) | 질문은 막지 않음. 단 **현재 태그로 대체도 안 함** |

접두어는 하드코딩하지 않고 **계기·출력 리스트에서 뽑습니다**
(현재 11종: AIT, PIT, FIT, LIT, XV, P, TIT, UV, RWP, LCV, R).
실물 리스트로 바꾸면 접두어도 함께 바뀝니다.

약한 등급에서 대체를 허용하지 않는 것이 중요합니다. 한쪽만 고치면
반대쪽이 뚫립니다 — 접두어 필터만 넣었을 때 `zzt-9999는 어디야` 가
다시 현재 화면 태그의 답을 내놨습니다.

```
zzt-9999는 어느 위치에 있어?  → 말씀하신 태그를 계기 리스트에서 찾지 못했습니다.
AIT-9999 알람 조회해줘        → AIT-9999 는 계기 리스트와 인터락 리스트에 없습니다.
AI 16xI 모듈 상태 표시 설명해줘 → (매뉴얼 QA 로 넘어감)
LCV-01 판넬 명 알려줘         → 인터락/출력 태그입니다. 판넬 이름을 추정하지 않습니다.
```

## 2. 계기 리스트가 두 곳에 있었습니다

`data/make_arrangement.py` 가 자기 폴더의 `DEMO_INSTRUMENT_LIST.xlsx`
사본을 먼저 보고, 없으면 config 로 넘어가게 되어 있었습니다. 제 실수입니다.

계기 4점(LIT-01A/01B/02A/02B)을 추가하셨는데 **도면만 옛 72점에 머물러**
있었습니다. 도면에는 CUB-A 18점, 조회에는 22점 — 둘 다 그럴듯해서
어긋났다는 사실이 드러나지 않습니다.

`config.INSTRUMENTS` 한 곳에서만 읽도록 고쳤고, 어느 파일을 읽었는지
실행할 때 찍습니다. v2 `data/` 의 사본은 지우십시오.

## 3. 공통원인 점검이 실제로 걸렸습니다

추가하신 이중화 레벨 계기가 **같은 카드에 물려 있습니다.**

```
CUB-A/R0/S1 (8점)
  ★ LCV-01-CLOSE-01  LCV-01 CLOSE  (OR)  — 보호 전부 상실
       같은 카드 ← LIT-01A, LIT-02A
  ★ LCV-01-CLOSE-02  LCV-01 CLOSE  (OR)  — 보호 전부 상실
       같은 카드 ← LIT-01B, LIT-02B
  둘 다 바이패스 불가 · 근거 P&ID Sh.007
```

A/B 이중화로 계기를 두 개씩 달아 놓고 **네 점을 슬롯 1 한 장에 모두**
결선한 형태입니다. 카드 한 장이 죽으면 이중화가 통째로 사라집니다.
분산 배치 검토에서 실제로 지적되는 형태고, 시연에서 보여주기에 좋습니다.

이전 데이터에서 0건이던 점검이 데이터가 바뀌자 2건을 짚었습니다.
점검기가 데이터를 실제로 읽고 있다는 뜻입니다.

## 5. selfcheck 22 → 24

```
매뉴얼 용어 오인 금지 [주입]  매뉴얼 용어가 태그 오타로 거절되지 않는가
                            낯선 접두어를 현재 태그로 대체하지 않는가
                            실재 접두어 오타는 여전히 거절하는가
배치도 최신 [주입]           배치도의 판넬별 점수가 현재 계기 리스트와 맞는가
```

두 번째는 이번 데이터 변경에서 실제로 어긋난 것을 잡으려고 넣었습니다.
값을 일부러 틀리게 넣어 검출되는 것도 확인했습니다.

```
CUB-A 도면 18점 ≠ 리스트 22점 — data/make_arrangement.py 를 다시 실행하십시오
```
